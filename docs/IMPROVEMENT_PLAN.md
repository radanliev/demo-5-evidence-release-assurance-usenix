## Phase 3 — Implementation plan

1. **Kill numeric drift (E1, E7)**
   a. Extend `write_frozen_metrics` to emit *all* hot numbers as macros
      (oneM build ms, peak ops/s, worker ratio, proof size/gen/verify,
      blinding per-record/total, DOM/screenshot per-step, overhead@100k).
   b. Rewrite prose to use the macros — no hot numeral stays hardcoded.
   c. New gate `check_numerals.py`: extract numerals from the .tex, compare
      against artifact JSON (rounded-equal match), whitelist structural
      constants (32-byte, 3600 s, 30 s skew, 1,050, 12, 10, policy values,
      years). Fails on any unbound drifting numeral. Wired into run_gates.
2. **Fix E5**: guard Optional signature args; annotate forensics locals.
3. **E6**: hypothesis property tests — Merkle proof round-trip for random
   leaf sets, canonical_json stability/determinism, blinding prefix law,
   policy fail-closed on random type fuzz.
4. **E3**: real baselines — `opa eval` a Rego schema-gate over the 12
   vectors; `cosign sign-blob/verify-blob` with a generated keypair for the
   artifact-gate model. Keep CI-gate as modeled (exit codes are its
   semantics). Update artifact JSON + §6.7 to say which baselines are
   executed vs modeled. Drop the upgrade if the tools misbehave; never fake
   an execution.
5. **E2**: add DBLP as third citation source in check_citations (verifies
   SWE-bench/ReAct-class papers). Specs/whitepapers stay honestly flagged.
6. **E4**: expand with grounded content only (no new unverified claims):
   limitations subsection (single-run timings, demo key, modeled-vs-executed
   baselines, semantic anomalies out of gate scope), A1–A5 ↔ V1–V12 mapping
   table, nonce-cache memory analysis already present + reproduction matrix.
7. **Phase 5**: full re-run (benchmarks, comparative, corpus, pytest,
   semgrep, bandit, mypy, chktex), rebuild ×2, artifact digest, gates green,
   commit, push, watch CI.

## Invariants

- No number is ever edited to silence a gate — artifacts regenerate, prose
  follows via macros, the gate verifies the binding.
- Baseline upgrades only via real executions; otherwise disclosed as modeled.
- New prose only describes what artifacts/code already support.
