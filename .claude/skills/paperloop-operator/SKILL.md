# Paperloop Operator

For the five `demo-*` repos with a `.paperloop/` directory (USENIX Security 2027
submission pipeline). Load this before touching the loop, the gates, or the
manuscript numbers.

## The one rule that matters

**Formatting is fixed automatically. Science is not.** Never edit a number,
result, or claim to make a gate go green — fix the underlying artifact or the
claim. Wrong numbers found by auditors go to `.paperloop/state/proposals/` for
the human, while the loop keeps working everything else.

## Commands

| Command | When |
|---|---|
| `python3 .paperloop/run_gates.py --build --render` | Measure without changing anything. Read `.paperloop/state/FINDINGS.md` after. |
| `python3 .paperloop/loop.py --forever --push --pr` | The full self-correcting loop (measure → review → write) |
| `python3 .paperloop/loop.py --list-fixers` | See which agent CLI it detected |
| `python3 .paperloop/loop.py --gates-only --render` | Chat-UI mode; paste `WORK_ORDER.md` into the chat |

Gate exit codes: `0` clean · `1` fixable findings · `2` gated, needs a human ·
`3` build broken.

## Repo map (demo-5 specifics)

- Manuscript: `docs/usenix_paper_manuscript.tex`; bib: `docs/references.bib`
- Frozen numbers: `docs/frozen_metrics.tex` — regenerated by
  `scripts/generate_paper_pdf.py` from `results/benchmark_summary.json`.
  **Never hand-edit frozen macros**; change the artifact and rebuild.
- Benchmarks: `scripts/run_release_benchmark.py`,
  `scripts/run_comparative_eval.py` → `results/*.json`
- Gates: `.paperloop/checks/` (citations, refs, venue, science, figures);
  venue rules in `.paperloop/venue.yaml` — correcting a wrong rule is fine,
  relaxing a rule to pass is not.
- Build = `python3 scripts/generate_paper_pdf.py` (runs pdflatex+bibtex 3×).
  After it, **check the PDF mtime actually moved** — a missing .sty makes the
  build fail silently and gates measure a stale PDF.

## Gotchas learned the hard way

- `check_science` is the weakest gate — it indexes artifact values but does
  not bind manuscript numbers to them. A wrong number in prose passes gates;
  only re-derivation catches it (see `adversarial-science-audit`).
- The reviewer agents in the loop did NOT catch fabricated references,
  fabricated statistics, or an auth bypass in the verification path. Trust
  deterministic gates for formatting; run adversarial re-derivation for
  science.
- Corpus/tamper suites: verify each vector's *implementation* matches its
  prose description (test names lie — one counted anomalies with
  `assert True`).
